# OjuTrack

OjuTrack est une application web qui permet de trouver ou de rechercher une personne ou des personnes similaires à une personne juste en uploadant une photo de celle-ci ou en en prenant une photo de celle-ci.
Elle permet a partir de cette photo de recuperer des informations sur la personne recherchée dans toutes les bases de données connues.

## Fonctionnalités

- Recherche par photo
- Photos Similarités
- Recuperation des informations de la personne recherchée
- Merging des informations de plusieurs bases de données

## Installation

Pour installer le projet, il faut d'abord cloner le repo et ensuite faire un `npm install` dans le dossier racine du projet.

- Pre-requis :
  - NodeJS
  - Npm
  - Vite
- Installation :
  - Cloner le repo : `git clone https://github.com/charbossles/OjuTrack.git`
  - Aller dans le dossier du projet : `cd OjuTrack`
  - Installer les dépendances : `npm install`
  - Lancer le serveur : `npm run dev`

## Développement

Le projet est développé en ReactJS et utilise le framework Vite et TailwindCSS.
React Router est utilisé pour la gestion des routes.
